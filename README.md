# ChemLab 3D — сапалық реакциялар зертханасы

Катиондар мен аниондардың сапалық реакцияларына арналған виртуалды химия зертханасы.

- **index.html** — 3D зертхана (Three.js r128, файл репозиторийде, сондықтан интернетсіз де жұмыс істейді)
- **lab2d.html** — 2D нұсқа

## Айфонға қосымша ретінде орнату
1. Safari-де сайттың мекенжайын ашыңыз: `https://nurbolat2107-source.github.io/chemlab3D/`
2. **Бөлісу** → **Add to Home Screen / На экран «Домой»**.
3. Басты экрандағы «ChemLab 3D» белгішесінен ашыңыз. Бір рет ашылғаннан кейін интернетсіз де жұмыс істейді.

## Жаңарту
Файлдарды ауыстырғаннан кейін `sw.js` ішіндегі `VERSION` мәнін өзгертіңіз (мысалы `chemlab-v2`), сонда телефондар жаңа нұсқаны алады.
